Lean by design

No model weights bundled. The <30 MB APK is a pure connector client — OkHttp with persistent WebSockets, SSE streaming, and Android Keystore-encrypted credential storage. If the network drops, a local fallback engine (LiteRT-LM) keeps the app responsive.

Get started

Download the APK, install it on your Android device, and scan the QR code from your desktop companion daemon.

  • APK — download from the releases page
  • Pairing — run the desktop companion on Windows 11
  • No Play Store dependency — sideload via ADB or distribute via the pilot channel

FAQ

What data leaves my phone?
Only the API calls you make to the provider you choose. No on-device inference, no model weights bundled.
What happens if the PC is off?
RemoteMesh is a standalone client. The PC daemon is only needed for handoff and mDNS discovery; without it you can still chat with your chosen provider.
Is my data stored on the device?
API credentials are stored in Android Keystore / EncryptedSharedPreferences, never in plain text.
Does it work offline?
The client is offline-capable for basic local fallback expectations (LiteRT-LM design goal), but active provider streaming requires network.
